## 5 Engine 两次卡住的事实

- Run 6：协调者唯一回合（19 s）的回复没有 task-dag；Engine 开「DAG 缺失」告警并停在 `awaiting-dag`，不自动重新请求规划；「立即检查并推进」返回 `not-active`、dispatched 0；03:38:42Z 取消（rev 27）。按裁决记「协议未执行完（作废）」，不计 W4。
- Run 6b：D1 答 retry 后，因上一次尝试留下 2 个未提交文件，派发被 `dispatch-blocked:workspace-dirty` 拒绝，未开任何告警；只有 15 分钟无进展规则能发现（06:57:09Z kick 返回 blocked、dispatched 0），07:14:13Z 取消（rev 75，k3a done、k3b cancelled）。
